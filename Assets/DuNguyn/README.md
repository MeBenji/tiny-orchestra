The Gramophone prefab requires external resources:
Source: https://assetstore.unity.com/packages/3d/props/gramophone-record-player-304065

Place the Gramophone directory into this DuNguyn directory.
Open the Gramophone prefab.
Locate and edit the SM_Gramophone and SM_VinylDisc prefabs.
The SM_Gramophone requires the SM_Gramophone mesh.
The SM_Gramophone requires the Machines_M, Wood_M, Speaker_M materials.
The SM_VinylDisc requires the SM_VinylDisc mesh.
The SM_VinylDisc requires the Machines_M materials.
